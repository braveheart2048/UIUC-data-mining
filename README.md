# UIUC Data Mining — Apriori Algorithm Implementation

This repository contains my personal implementation and experiments based on Coursera's **Data Mining Specialization** (taught by Prof. Jiawei Han et al.).

> ⚠️ **Disclaimer:** The code is for learning reference only and should not be used for direct course assignment submissions.

## Project Structure

| File | Description |
|------|-------------|
| [`assignment1.py`](assignment1.py) | Part 1: Counts frequent 1-itemsets from the dataset |
| [`assignment2.py`](assignment2.py) | Part 2: Implements the full Apriori algorithm to mine all frequent itemsets |
| [`utils.py`](utils.py) | Helper functions for the Apriori algorithm (support calculation, candidate pruning, itemset joining) |
| [`Mining using Apriori.txt`](Mining%20using%20Apriori.txt) | Input dataset (transaction records with categories) |
| [`part1.txt`](part1.txt) | Output from Part 1 (1-itemsets with support counts) |
| [`part2.txt`](part2.txt) | Output from Part 2 (all frequent itemsets with support counts) |
